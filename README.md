# Menara Stik (Android)

Game panahan bertahan di menara, 10 level, karakter stik di atas kertas berumput.
Dibungkus dengan Capacitor menjadi aplikasi Android.

## Cara mendapatkan APK
1. Upload semua isi folder ini ke repository GitHub (termasuk folder `.github`).
2. Buka tab **Actions**, pilih **Build APK**, lalu **Run workflow** (atau cukup push ke branch main).
3. Setelah selesai (sekitar 5 menit), buka run tersebut, unduh **menara-stik-apk** di bagian Artifacts, ekstrak zip-nya.
4. Kirim `app-debug.apk` ke ponsel Android, buka, dan izinkan "instal dari sumber tidak dikenal".

## Mengubah game
Seluruh game ada di `www/index.html`.
